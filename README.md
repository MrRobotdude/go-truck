# Go Truck

Personal HCI class project by Doddie Prawarjito. Preserved five-page HTML/CSS/JavaScript design, restored for a reproducible portfolio demonstration.

## Run

Open `index.html`, or run `python -m http.server 8080` from this folder. No dependency installation or backend required. `npm run check` validates local links/assets and JavaScript syntax. GitHub Pages deploys on main.

## Completed restoration

- Validated fields with readable feedback; accepted non-.com email domains.
- Fixed the address validator referencing a nonexistent message field; added password validation.
- Forms no longer submit to a nonexistent server or falsely claim an email was sent. Password input is cleared after successful validation; no personal information is stored.
- Scoped slideshow selectors, pause/reduced-motion behavior, keyboard controls, focus-visible styling and responsive overrides.
- Consistent page labels, accessible navigation and a clear design-demo notice.
